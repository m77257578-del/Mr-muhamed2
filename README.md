# منصة الأستاذ محمد عبد المقصود

منصة تعليمية متكاملة للغة العربية من الصف الرابع الابتدائي حتى الصف الثالث الثانوي، مبنية باستخدام **React**, **Vite**, **TypeScript**, **Tailwind CSS**, و**Express**.

---

## مميزات المنصة

- **مساحة الطالب**:
  - تسجيل حساب جديد وتسجيل الدخول برقم الهاتف وكلمة السر
  - استعراض الكورسات والمذكرات والفيديوهات مع علامة مائية باسم ورقم الطالب وحماية من التحميل
  - حل الامتحانات الإلكترونية (اختياري، مقالي، مختلط) مع تصحيح تلقائي أو بمساعدة الذكاء الاصطناعي
  - مراجعة الإجابات ونموذج الإجابة وخدمة "تدرّب على أخطائي"
  - الملاحظات الذكية وتدوين ملاحظات الدروس
  - المساعد الذكي مع دعم القراءة الصوتية (Text-to-Speech)
  - مراسلة الأستاذ واستلام الردود
  - تفعيل الأكواد المدفوعة ومتابعة فترة الاشتراك

- **مساحة ولي الأمر**:
  - الدخول برقم هاتف الطالب ونفس كلمة السر
  - متابعة مستوى الطالب: الفيديوهات المشاهدة، الملفات المفتوحة، الامتحانات المنجزة، متوسط الدرجات، والتقدير العام

- **لوحة تحكم الأستاذ**:
  - إدارة الطلاب وتمديد الاشتراكات وإعادة ضبط كلمات المرور وحجب أو تفعيل الحسابات
  - نشر الكورسات وتحديد الأسعار وفترة الصلاحية
  - رفع الفيديوهات والمذكرات وملفات PDF والواجبات والصور أو إضافة روابط خارجية
  - توليد أكواد التفعيل ومشاركتها مباشرة عبر واتساب
  - بناء الامتحانات الإلكترونية بديناميكية تامة
  - تصحيح الإجابات ومراجعة التظلمات والرد على رسائل الطلاب
  - تخصيص إعدادات المنصة وصورة الغلاف وطرق الدفع

---

## التشغيل والتطوير

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build

# الفحص والتأكد من سلامة الأنواع
npm run lint
```
